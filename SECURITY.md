# Security policy

## Reporting a vulnerability

Please report security issues privately using GitHub's **Report a vulnerability** button on the **Security** tab of this repository. Do not open a public issue.

Include what you found, how to reproduce it and the impact you expect. You will get an acknowledgement, and fixes are coordinated before any public disclosure.

## Scope

This repository may contain research code. Anything described as an experiment or a reference implementation is not intended for production use.
